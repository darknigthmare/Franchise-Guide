# FranchiseGuide Suite 0.34.0

Base : ZIP V0.33 fourni, SHA-256 `65343acbb86b829b7ebdca93030ff32d1520b070130777507c7ce0a4fcd09540`.

V0.34 ajoute un scanner multi-catégories de franchises avec pages indépendantes, reprises ciblées et commit atomique de suggestions grisées. Les résultats ne deviennent jamais automatiquement suivis ou vus.

PC Java17+ et Web Node22+ restent inclus. Android reste en sources. Les catalogues publics précédents, imports, listes, univers, statistiques, sauvegardes protégées et connexions optionnelles sont conservés.

La campagne de reconstruction a exécuté 1 465 tests Node disponibles, 9 assertions Chromium ciblées, 9 assertions Kotlin/JVM et les contrôles PC. Deux suites Node dépendant de jsdom/fake-indexeddb restent exclues. Aucun compte réel, PWA installée ou appareil Android n’est validé.
