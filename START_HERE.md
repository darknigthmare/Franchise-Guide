# Démarrage — FranchiseGuide 0.36.0

Consulter le [README](README.md) pour les prérequis, lanceurs et commandes de build.

1. Exporter sa bibliothèque depuis une ancienne version avant migration.
2. Fermer ses anciennes fenêtres et anciens lanceurs.
3. Lancer `npm start` pour le Web personnel ou le lanceur dans `desktop/` pour le PC.
4. Ouvrir les réglages pour les comptes optionnels et utiliser le bouton + de chaque catégorie.
5. Importer une sauvegarde depuis Plus, vérifier l’aperçu, puis confirmer.

Les exports JSON et protégés sont interopérables. Le schéma portable reste 11 ; les secrets ne sont pas inclus dans ces exports. Le JAR Java utilise le même moteur Web. L’état Android et les limites de validation figurent dans [le rapport QA](docs/QA_REPORT.md).
